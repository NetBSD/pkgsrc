# -----------------------------------------------------------------------------
# Example: Bulk test run (testing all safe syscalls automatically)
# -----------------------------------------------------------------------------
# This example demonstrates how to run the entire LTP syscall suite on NetBSD.
#
# NOTE: Syscalls known to cause severe issues (e.g., kernel panics or system
# hangs) are automatically skipped in this mode to ensure the test run finishes.
# To test those specific syscalls, use the '-s' option.
#
# Prerequisite: The compat_linux_test_project package installed.
#
# 1. Run the script. We use '-r' to enable reproducible output (essential if
#    we want to compare these logs later) and '-d' to specify the output directory:
#
# $ compat_linux_test_project -r -d /tmp/bulk_logs
