# -----------------------------------------------------------------------------
# Example: Comparing logs using -c / --compare-to
# -----------------------------------------------------------------------------
# This workflow is essential for spotting regressions, fixes, or new tests
# after kernel updates. It compares a new set of logs against a reference baseline.
#
# Prerequisite: Runs should be executed with the reproducible flag ('-r').
#
# -----------------------------------------------------------------------------
# Scenario A: Comparing against the default package reference
# -----------------------------------------------------------------------------
# If you don't specify a directory with -b, it defaults to the reference logs
# shipped with the package.
#
# 1. Generate your current run:
# $ compat_linux_test_project -r -d /tmp/current_run
#
# 2. Compare it against the default reference:
# $ compat_linux_test_project -c /tmp/current_run

# -----------------------------------------------------------------------------
# Scenario B: Comparing against a custom baseline
# -----------------------------------------------------------------------------
# Useful if you are testing incremental changes and want to compare a new run
# with a run you did before.
#
# 1. Generate the baseline run (done before your kernel changes):
# $ compat_linux_test_project -r -d /tmp/my_baseline
#
# 2. Generate the current run (done after your kernel changes):
# $ compat_linux_test_project -r -d /tmp/my_new_run
#
# 3. Compare them by passing the baseline directory to -c:
# $ compat_linux_test_project -c /tmp/my_new_run -b /tmp/my_baseline

# -----------------------------------------------------------------------------
# Scenario C: Restricting comparison to specific syscalls
# -----------------------------------------------------------------------------
# You can combine '-c' with '-s' to limit the comparison to a specific subset
# of syscalls. This is extremely useful if you have a full bulk run but only
# want to analyze the results of one or two syscalls.
#
# $ compat_linux_test_project -c /tmp/my_new_run  -b /tmp/my_baseline -s readv
